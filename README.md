### Инструкция:
Программа находит разницу между плоскими и вложенными деревьями файлов YML и JSON.

Вывод команды "gendiff --help":

```
gendiff -h

Generate diff

Usage:
  gendiff (-h|--help)
  gendiff (-v|--version)
  gendiff [--format <fmt>] <firstFile> <secondFile>

Options:
  -h --help                     Show this screen
  -v --version                  Show version
  --format <fmt>                Report format [default: stylish]
```

### Установка:
Клонируйте репозиторий в свою систему. -
```
git clone https://github.com/StanislavSol/python-project-50.git
```
В терминале введите команду -
```
make install
```
### Использование:
```
make gendiff [--format <fmt>] <firstFile> <secondFile>
```
